# Screenshots for the root README

Drop PNGs here with these exact filenames — the root `README.md` references them:

| Filename | What to capture |
|---|---|
| `home.png` | Home page — the Apple-TV-style catalog grid (`http://localhost:3001`) |
| `player.png` | A video playing with the **QoE overlay open** (click the gauge icon — shows quality, FPS, bitrate, dropped frames) |
| `admin.png` | Admin studio (`/admin`) — the dashboard stat cards + catalog table |
| `grafana.png` | A Grafana dashboard showing SLO / burn-rate or origin/QoE panels (`http://localhost:3000`) |

Tips:
- Use PNG, ~1600px wide, dark theme to match the UI.
- Optional extras you can add and link from the README: `edit-drawer.png` (per-title editor),
  `imax.png` (IMAX fill mode), `minio.png` (MinIO console object browser).
